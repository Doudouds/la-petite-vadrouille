# Réponse de base pour la section Data Safety

Point de départ à vérifier avant soumission:

- pas de création de compte
- pas de collecte volontaire de données personnelles identifiantes
- pas de partage publicitaire
- stockage local technique sur l'appareil pour le cache des tracés et profils d'altitude
- communications réseau avec services cartographiques et de données tiers uniquement pour le fonctionnement de l'application

À confirmer dans la Play Console selon la version réellement publiée et les services finalement activés.
